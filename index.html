Projeto extensionista universitário

Sistema web funcional para apoio a uma comunidade parceira

Plataforma acessível para cadastrar demandas, organizar atendimentos, acompanhar prioridades e facilitar a comunicação entre alunos e comunidade.

Imagem inicial Substitua por foto da comunidade, banner ou print do sistema

Contexto

Sobre o projeto

Comunidade parceira

Associação Comunitária Esperança, grupo fictício usado como modelo. Troque este nome pela comunidade real atendida pelo seu grupo.

Problema identificado

Falta de uma ferramenta simples para registrar pedidos, acompanhar necessidades e organizar ações sociais.

Solução proposta

Um sistema web responsivo, acessível e funcional para cadastro, busca, edição e exclusão de demandas comunitárias.

Sistema funcional

Cadastro de demandas da comunidade

Os dados são salvos no navegador usando localStorage.

Preencha os campos para registrar uma demanda. Campos com * são obrigatórios.
